# Student Performance Analytics (R & Shiny UI Project)

Is mini-project me R script aur interactive Shiny UI Dashboard dono include hain.

## Folder Structure
- `data/students.csv` : Sample dataset
- `script.R` : Main R script (data processing + image charts generation)
- `app.R` : Interactive Shiny Web UI App
- `output/` : Output files (csv aur png images)

## How to Run

### Option 1: Basic R Script Run (Console Output)
RStudio me `script.R` open karein aur `Run` button dabaein.

### Option 2: Interactive Web UI App Run
1. RStudio me `shiny` package install karein (agar nahi hai):
   `install.packages("shiny")`
2. `app.R` file open karein.
3. Top-right side me **Run App** button par click karein.
